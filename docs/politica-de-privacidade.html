Política de Privacidade - MeuBolso

Esta Política de Privacidade descreve como o aplicativo MeuBolso trata as informações utilizadas durante o uso de suas funcionalidades.

Na versão atual, os dados cadastrados no MeuBolso permanecem armazenados localmente no dispositivo e não são enviados para um servidor próprio.

1. Informações fornecidas pelo usuário

O MeuBolso permite o cadastro de movimentações financeiras, que podem incluir descrição, valor, tipo de movimentação (receita ou despesa), categoria e data.

Essas informações são fornecidas diretamente pelo usuário para permitir a organização das finanças, o cálculo do saldo e a exibição do histórico de movimentações no aplicativo.

2. Armazenamento das informações

Na versão atual do aplicativo, os registros cadastrados são armazenados localmente no dispositivo por meio do armazenamento interno da aplicação.

O MeuBolso não exige criação de conta e não possui, nesta versão, servidor próprio para armazenar ou sincronizar as movimentações cadastradas pelo usuário.

3. Compartilhamento de dados

O MeuBolso não compartilha as movimentações financeiras cadastradas pelo usuário com terceiros.

Os dados também não são utilizados para publicidade direcionada, venda de informações ou criação de perfis comerciais.

4. Permissões do dispositivo

As funcionalidades atuais do MeuBolso não dependem de acesso à câmera, microfone, localização, contatos ou galeria de fotos.

Caso versões futuras passem a utilizar alguma permissão adicional, esta Política de Privacidade deverá ser atualizada.

5. Segurança

O usuário é responsável por manter o seu dispositivo protegido por recursos de segurança adequados, como senha, PIN, biometria ou bloqueio de tela.

Como os dados são armazenados localmente, a remoção do aplicativo, a limpeza de seus dados ou a perda do dispositivo pode ocasionar a perda das informações registradas.

6. Controle dos dados

Como as informações permanecem armazenadas localmente no dispositivo, o usuário mantém controle direto sobre os registros inseridos no aplicativo.

A exclusão dos dados pode ocorrer por meio das funcionalidades disponíveis no próprio aplicativo ou pela remoção dos dados do aplicativo no sistema operacional.

7. Crianças e adolescentes

O MeuBolso não foi desenvolvido especificamente para crianças e não contém funcionalidades destinadas à coleta intencional de dados de menores.

O aplicativo é apresentado como uma ferramenta de controle financeiro pessoal voltada ao público geral e adulto.

8. Alterações desta política

Esta Política de Privacidade poderá ser atualizada caso o aplicativo receba novas funcionalidades que alterem a forma de armazenamento, coleta, utilização ou compartilhamento de dados.

A versão mais recente permanecerá disponível neste endereço.
